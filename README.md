# خارطة طريق Front-End — من الصفر إلى الجاهزية للعمل

مسار تعليمي خطوة بخطوة يأخذك من مبتدئ تمامًا إلى مطور واجهات أمامية جاهز للعمل.

## ماذا ستتعلم

0. أساسيات الويب
1. HTML + CSS
2. JavaScript
3. Git & GitHub
4. TypeScript
5. React
6. مهارات Front-End الحديثة
7. اختبار التطبيقات Testing
8. مواضيع متقدمة

كل مرحلة تشمل كورسات مقترحة ومشاريع عملية والمصادر الرسمية.

## كلمة المرور

```
Frontend@2026
```

افتح ملف `index.html` وأدخل كلمة المرور لعرض خارطة الطريق كاملة.
