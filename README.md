## 🚀 How to Use

1. Clone the repo:
   ```bash
   git clone https://github.com/Elhendawy-1/Front-End-Development-Roadmap.git
   ```
2. Open `index.html` directly in your browser (double-click, or use VS Code Live Server).
   Or view the live version via GitHub Pages (same `index.html`).
3. Enter the password when prompted:
   ```
   Frontend@2026
   ```
   > To change it, open the HTML file and edit `const PASSWORD = "Frontend@2026";`
4. Start from **Phase 0 → Phase 8** in order.
5. Use the **🌙 Dark Mode** button (top-right) — preference is saved automatically.
6. Press `Enter` in the password field to unlock quickly.

No build step, no dependencies — just one HTML file served as `index.html`.

## 🗺️ Roadmap Overview

| # | Phase | Duration | Focus |
|---|-------|----------|-------|
| 0 | **Web Fundamentals** | 1–2 days | Internet vs Web, Client/Server, DNS, HTTP/HTTPS, DevTools, VS Code + Terminal |
| 1 | **HTML + CSS** | 4–6 weeks | Semantic HTML, Accessibility, Box Model, Flexbox, Grid, Responsive Design |
| 2 | **JavaScript** | 6–10 weeks | Fundamentals, Arrays/Objects, ES6+, Closures, DOM, Browser APIs, Async, Fetch/API |
| 3 | **Git & GitHub** | 1 week | init/add/commit, branches, push/pull/clone, PRs, README. Start using from Phase 1 |
| 4 | **TypeScript** | 2–3 weeks | Types, Interfaces, Generics, Narrowing, TS with React |
| 5 | **React** | 4–6 weeks | JSX, Props/State, Hooks, Router, Forms, API fetching |
| 6 | **Modern Front-End Skills** | 4–6 weeks | Auth/JWT, Forms/Zod, Redux/TanStack Query, Performance, A11y, Deployment, Security, SEO |
| 7 | **Testing** | 1–2 weeks | Jest, React Testing Library, Integration, Cypress/Playwright (optional) |
| 8 | **Advanced Topics** | Ongoing | Junior → Intermediate → Advanced (Next.js, GraphQL, CI/CD, Micro-frontends, etc.) |
| ★ | **Course Summary + Docs** | — | All courses + official documentation in one table |

**Estimated total: 6–9 months** at 2–4 hours of focused study per day. Timeline varies by practice time and project depth.

## 🧠 Learning Philosophy

> **Learn → Practice → Build Projects → Improve**

- Code every day, even 30 minutes
- Build projects from Phase 1, use Git from Phase 1
- One primary course → Practice → Projects → Supplement only when stuck
- Read MDN docs, Google errors before asking
- Don't watch 3 courses for the same topic, don't skip HTML/CSS for React, don't memorize — understand

**DO:** daily coding, portfolio, community, documentation
**DON'T:** tutorial hopping, rushing phases, comparing yourself to others, building projects only in your head
