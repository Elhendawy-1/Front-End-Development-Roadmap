Web Fundamentals

1–2 days

Understand how the web works before writing any code. This phase is short by design.

  • Internet vs Web — The internet is the infrastructure. The web is a service on top of it.
  • Client / Server — Browser sends request → server sends response.
  • DNS — Translates domain names into IP addresses.
  • HTTP/HTTPS — Protocols for transferring data. HTTPS is encrypted.
  • Browser DevTools — Your #1 debugging tool.
  • VS Code + Terminal basics — Your development environment.

HTML + CSS

4–6 weeks

Part 1 — HTML

Key Focus: Semantic HTML, Accessibility, Clean Structure

  • Document structure, elements, tags, attributes
  • Headings, paragraphs, text formatting, links, images, lists, tables
  • Forms, input types, buttons, audio, video, iframe
  • Semantic HTML: <header>, <footer>, <nav>, <main>, <section>, <article>
  • Accessibility: alt text, aria-* labels, form labels, heading hierarchy

Part 2 — CSS Fundamentals

Key Focus: Box Model, Specificity, Positioning

  • Selectors, specificity, cascade, inheritance
  • Colors, units (px, rem, em, vw, vh), typography
  • Box model (box-sizing: border-box), display, positioning
  • Pseudo-classes, pseudo-elements, CSS variables

Part 3 — Flexbox

Key Focus: Centering, Navigation Bars, Card Layouts

  • Main/Cross axis, flex-direction, justify-content, align-items
  • flex-wrap, gap, flex-grow/shrink/basis

Part 4 — CSS Grid

Key Focus: Page Layouts, Grid Areas, Responsive Grids

  • Grid container, columns/rows, fr unit, repeat(), minmax()
  • Grid areas, grid-column/row, named lines

Part 5 — Responsive Design

Key Focus: Mobile-First, clamp(), Media Queries

  • Media queries, responsive units, min()/max()/clamp()
  • Responsive typography, images, breakpoints

JavaScript

6–10 weeks

Part 1 — JS Fundamentals

Key Focus: let vs const, Type Coercion, Functions

  • Variables, data types, operators, type conversion
  • Conditions, loops, functions, scope

Part 2 — Arrays & Objects

Key Focus: map, filter, reduce, Destructuring, Spread

  • Array methods (map, filter, reduce, find, some, every)
  • Destructuring, spread/rest operators

Part 3 — ES6+

Key Focus: Arrow functions, Modules, Optional chaining

  • Template literals, arrow functions, default parameters
  • Modules (import/export), optional chaining (?.), nullish coalescing (??)

Part 4 — Deeper Concepts

Key Focus: Closures, this, Event Loop, References vs Values

  • Hoisting, closures, execution context, call stack
  • this keyword, shallow vs deep copy

Part 5 — DOM

Key Focus: Event Delegation, event.preventDefault(), Dynamic Element Creation

  • Selecting, traversing, changing elements
  • Event listeners, bubbling, delegation
  • Forms and form validation

Part 6 — Browser APIs

Key Focus: localStorage, Timers

  • localStorage/sessionStorage, setTimeout/setInterval

Part 7 — Asynchronous JavaScript

Key Focus: async/await, Error Handling, Event Loop

  • Callbacks, Promises, async/await
  • try/catch, microtasks vs macrotasks

Part 8 — HTTP, JSON & APIs

Key Focus: fetch(), Status Codes, CORS

  • REST basics, HTTP methods, status codes
  • JSON, fetch() with async/await

Git & GitHub

1 week

When to start: Start using Git from Phase 1 (commit your projects). Learn formally here.

  • git init, status, add, commit, log, .gitignore
  • Branches: branch, switch, merge
  • Remote: remote, push, pull, clone
  • GitHub: repositories, README, Pull Requests, Issues

TypeScript

2–3 weeks

Prerequisites: Strong JavaScript foundation required.

  • Why TypeScript exists, type inference, annotations
  • Interfaces, type aliases, union/intersection types
  • Generics, narrowing, utility types
  • TypeScript with React (props, state, events)

React

4–6 weeks
  • JSX, Components, Props, State, Events
  • Conditional rendering, Lists, Keys, Forms
  • Hooks: useState, useEffect, useRef, useContext, Custom Hooks
  • Component composition, folder structure, state management
  • React Router (routes, nested routes, protected routes)
  • APIs with React (fetching, loading/error states, auth)

Modern Front-End Skills

4–6 weeks
  • Authentication & Authorization (JWT, protected routes)
  • Form Handling & Validation (React Hook Form, Zod)
  • State Management (Context, Redux Toolkit, TanStack Query)
  • Performance (memo, useMemo, useCallback, lazy loading)
  • Accessibility (ARIA, keyboard nav, screen readers)
  • Deployment (Vercel, Netlify, GitHub Pages)
  • Web Security Basics (XSS, CSRF, HTTPS)
  • SEO Basics (meta tags, semantic HTML, SSR)
7

Testing

1–2 weeks
  • Unit Testing (Jest)
  • Component Testing (React Testing Library)
  • Integration Testing (API mocking)
  • E2E Testing (Cypress / Playwright — optional for junior)
8

Advanced Topics

Ongoing

Junior Level (Learn Now)

  • Advanced React patterns, performance optimization
  • Code splitting, lazy loading, memoization
  • Advanced TypeScript, web accessibility
  • Browser rendering pipeline, service workers

Intermediate Level (1–2 Years)

  • Next.js (SSR/SSG), Server Components
  • Advanced state management (Zustand, Jotai)
  • WebSockets, GraphQL, CI/CD, Docker basics

Advanced / Optional

  • Micro-frontends, WebAssembly, Web Workers
  • Advanced animation (Framer Motion, GSAP)
  • Monorepo tools (Turborepo, Nx)

  • Rush through phases
